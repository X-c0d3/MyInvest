# MyInvest

เว็บแอปบันทึกการลงทุน หุ้นไทย ETF หุ้นต่างประเทศ และ Crypto แทน Google Sheets ทุกอย่างคำนวณให้อัตโนมัติ ไม่ต้องเขียนสูตรเอง

## ฟีเจอร์

- **Login / สมัครสมาชิก**: รหัสผ่าน hash ด้วย scrypt และ session เก็บใน SQLite (cookie httpOnly อายุ 30 วัน) ข้อมูลแยกตาม user
- **พอร์ต & ค่าเงิน**: แยกได้หลายพอร์ต (หุ้น/ETF หรือ Crypto) และแต่ละพอร์ตกำหนดสกุลเงินเองได้ (THB, USD, …) ตอนสมัครจะสร้าง "พอร์ตหุ้น" และ "พอร์ต Crypto" ให้อัตโนมัติ
- **หลายสกุลเงิน**: ทุกยอดในหน้าภาพรวมแปลงเป็นบาท ใช้อัตราที่ตั้งเอง หรือถ้าไม่ได้ตั้ง จะใช้อัตราเฉลี่ยจากยอดบาทที่โอนเข้าพอร์ตนั้น
- **บัญชีผู้ใช้**: เปลี่ยนรหัสผ่าน (เมื่อเปลี่ยนแล้วอุปกรณ์อื่นจะถูก logout) และออกจากระบบอุปกรณ์อื่นทั้งหมด
- **ธีม**: สว่าง / มืด / ตามระบบ จำค่าไว้ในเบราว์เซอร์
- **ฝาก-ถอน**: บันทึกพร้อมบัญชีและหมายเหตุ และระบุที่มาของเงินฝาก: 💰 เงินใหม่ / 🎁 ปันผลนำกลับ / 📈 กำไรขาย (ย้อนหลัง) ถ้าเป็นพอร์ตต่างประเทศ ใส่ยอดบาทที่โอนจริงได้ เพื่อให้นับกำไร/ขาดทุนจากค่าเงินด้วย
- **ซื้อ-ขาย**: ระบุชนิดได้ทั้งหุ้น ETF และ Crypto (จำนวนทศนิยมได้) มีค่าธรรมเนียมและโบรกเกอร์/Exchange
- **ปันผล**: ใส่จำนวนหุ้น, ปันผลต่อหุ้น, % ภาษี (ค่าเริ่มต้น 10%), วัน XD และวันจ่าย แล้วระบบคำนวณยอดรวม ภาษี และยอดสุทธิให้
- **หลักทรัพย์ที่ถือ**: ใส่จำนวนและต้นทุนเฉลี่ยตามแอปโบรกได้ตรงๆ (ปุ่ม ✏️) และใส่เงินสดในโบรก หลังจากนั้นการซื้อขายใหม่จะคำนวณต่อให้เอง
- **ภาพรวม**: มูลค่าพอร์ต, เงินต้น, กำไร/ขาดทุนรวม, เป้าหมายพร้อมยอดที่ยังขาด และสรุปรายปี
- ทุกตารางเพิ่ม / แก้ไข / ลบได้ และกรองตามพอร์ตได้

## วิธีคำนวณ

| ค่า | สูตร |
| --- | --- |
| ต้นทุนเฉลี่ย | วิธี average cost: ค่าธรรมเนียมซื้อรวมในต้นทุน ค่าธรรมเนียมขายหักจากเงินที่ได้ |
| กำไรที่ขายแล้ว | เงินที่ได้จากการขาย − ค่าธรรมเนียม − (ต้นทุนเฉลี่ย × จำนวนที่ขาย) |
| ปันผลสุทธิ | จำนวนหุ้น × ปันผลต่อหุ้น × (1 − ภาษี%) |
| เงินต้น | เงินฝากทุกแหล่ง (เงินใหม่ + เงินทบต้นจากปันผล/กำไรขาย) − ถอน |
| เงินสดในโบรก | ยอดที่ผู้ใช้ใส่เองจากแอปโบรก (หน้าหลักทรัพย์ที่ถือ) ถ้ายังไม่ใส่ นับเป็น 0 |
| มูลค่าพอร์ต | หุ้นที่ถือ (ราคาล่าสุด หรือราคาทุน) + เงินสดในโบรก |
| กำไร/ขาดทุนที่ไม่ได้บันทึก | เงินสดในโบรก − เงินสดตามที่บันทึกในแอป (ฝาก − ถอน − ซื้อ + ขาย) คือผลการซื้อขายในอดีตที่ไม่ได้บันทึก |
| มูลค่าพอร์ต | เงินสดคงเหลือ + มูลค่าหลักทรัพย์ (ใช้ราคาทุนถ้ายังไม่ได้ใส่ราคาล่าสุด) |
| ปันผล % ต่อปี | ปันผลสุทธิของปี ÷ เงินต้นสะสม (ฝาก − ถอน) ณ สิ้นปี |
| ผลตอบแทน % ต่อปี | (กำไรที่ขายแล้ว + ปันผลสุทธิ) ÷ เงินต้นสะสม ณ สิ้นปี |
| เงินต้น (บาท) ของพอร์ตต่างประเทศ | ยอดบาทที่โอนจริง (ถ้าไม่ได้ใส่ จะแปลงด้วยอัตราปัจจุบัน) |
| กำไร/ขาดทุนรวม (บาท) | มูลค่าพอร์ตวันนี้ (บาท) + ปันผลที่ยังอยู่นอกพอร์ต − เงินต้น (รวมผลจากค่าเงินแล้ว) |

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000 แล้วสมัครสมาชิก

ฐานข้อมูลอยู่ที่ `data/myinvest.db` (เปลี่ยนตำแหน่งได้ด้วย env `DATABASE_PATH`) สำรองข้อมูลได้ด้วยการ copy ไฟล์นี้ ถ้าต้องการเริ่มใหม่ให้ลบโฟลเดอร์ `data/`

## Deploy บน VPS (Docker)

มี `Dockerfile`, `docker-compose.yml` และ `Caddyfile` ให้พร้อม แอปรันด้วย user ที่ไม่ใช่ root ฐานข้อมูลเก็บในโฟลเดอร์ `data/` บนเครื่อง VPS (mount เข้า container) ข้อมูลจึงไม่หายตอนอัปเดต และสำรองได้แค่ copy โฟลเดอร์นี้ แอปเปิดที่ **port 3004** ของ VPS

### สิ่งที่ต้องมี
- VPS ที่ติดตั้ง Docker และ Docker Compose แล้ว และเปิด port 3004 (หรือ port ของ reverse proxy ที่ใช้)
- แนะนำให้มี HTTPS ด้านหน้า เช่น nginx / Caddy / Cloudflare ที่ชี้มาที่ `localhost:3004`

### ติดตั้งครั้งแรก
```bash
git clone <repo ของคุณ> myinvest && cd myinvest
cp .env.example .env
mkdir -p data && sudo chown 1000:1000 data   # ให้ user ใน container (uid 1000) เขียนโฟลเดอร์นี้ได้
docker compose up -d --build
```
เปิด `http://<IP ของ VPS>:3004` (หรือโดเมนที่ proxy ชี้มา) แล้วสมัครบัญชีแรก หลังจากมีบัญชีแล้ว ระบบจะปิดรับสมัครเองโดยอัตโนมัติ ถ้าต้องการเพิ่มผู้ใช้ภายหลัง ให้ตั้ง `ALLOW_REGISTRATION=true` ใน `.env` แล้วรัน `docker compose up -d` จากนั้นตั้งกลับเป็น `false`

> ⚠️ ถ้าเปิดผ่าน `http://IP:3004` ตรงๆ (ไม่มี HTTPS) ต้องตั้ง `COOKIE_SECURE=false` ใน `.env` ไม่อย่างนั้นจะ login ไม่ติด แต่รหัสผ่านและข้อมูลการเงินจะส่งผ่านเน็ตแบบไม่เข้ารหัส จึงแนะนำให้ใส่ HTTPS ด้านหน้าแล้วคง `COOKIE_SECURE=true`

**ใช้ Caddy ที่แถมมาทำ HTTPS ให้ (ไม่บังคับ):** ตั้ง `DOMAIN` ใน `.env` เป็นโดเมนที่ DNS ชี้มาที่ VPS เปิด port 80, 443 แล้วรัน `docker compose --profile caddy up -d --build`

### ย้ายข้อมูลจากเครื่องตัวเองขึ้น VPS
```bash
# บนเครื่องตัวเอง: สร้างสำเนาฐานข้อมูลที่สมบูรณ์ (ทำได้แม้ dev server ยังเปิดอยู่)
node -e "require('better-sqlite3')('data/myinvest.db',{readonly:true}).backup('myinvest-upload.db')"
scp myinvest-upload.db <user>@<vps>:~/myinvest/

# บน VPS: วางไฟล์ไว้ในโฟลเดอร์ data/ ชื่อ myinvest.db
docker compose stop app
mv myinvest-upload.db data/myinvest.db
rm -f data/myinvest.db-wal data/myinvest.db-shm   # ไฟล์ค้างของฐานข้อมูลเดิมบน VPS (ถ้ามี)
sudo chown 1000:1000 data/myinvest.db
docker compose start app
```
ตอนเปิดใช้งาน ระบบจะอัปเดต schema ของฐานข้อมูลให้เอง (migration)

### อัปเดตเวอร์ชัน
```bash
git pull && docker compose up -d --build
```

### สำรองข้อมูลบน VPS
ฐานข้อมูลอยู่ที่ `data/` บนเครื่อง VPS ใช้คำสั่งนี้ได้แม้แอปเปิดอยู่ จะได้ไฟล์เดียวที่ข้อมูลครบ (รวม `-wal` แล้ว):
```bash
docker compose exec app node -e "require('/app/node_modules/better-sqlite3')('/app/data/myinvest.db',{readonly:true}).backup('/app/data/backup-'+new Date().toISOString().slice(0,10)+'.db')"
```
ไฟล์ `data/backup-<วันที่>.db` จะอยู่บน VPS ทันที หรือถ้าหยุดแอปก่อน (`docker compose stop app`) จะ copy ทั้งโฟลเดอร์ `data/` ไปเก็บเลยก็ได้ แนะนำให้ตั้ง cron ไว้สำรองทุกวัน และเก็บไฟล์สำรองไว้นอก VPS ด้วย

### ค่าใน `.env`
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `APP_PORT` | `3004` | port บน VPS ที่เปิดให้เข้าแอป |
| `DATA_DIR` | `./data` | โฟลเดอร์บน VPS ที่เก็บฐานข้อมูล |
| `DOMAIN` | (ว่าง) | ใช้เฉพาะกับ `--profile caddy` โดเมนที่ Caddy จะออกใบรับรอง HTTPS ให้ |
| `ALLOW_REGISTRATION` | `false` | `true` = เปิดรับสมัครเสมอ ส่วน `false` = รับสมัครได้เฉพาะตอนที่ยังไม่มีผู้ใช้ |
| `COOKIE_SECURE` | `true` | ส่ง cookie เข้าสู่ระบบผ่าน HTTPS เท่านั้น ตั้ง `false` ถ้าเปิดผ่าน http ตรงๆ |

## โครงสร้าง

- `lib/db.ts`: เชื่อมต่อ SQLite และ schema
- `lib/auth.ts`: password hashing, session และ `requireUser()`
- `lib/data.ts`: query และ mutation ทั้งหมด (scope ด้วย `user_id` ทุกตัว)
- `lib/calc.ts`: คำนวณ holdings, กำไร และสรุปรายปี
- `app/actions.ts`, `app/auth-actions.ts`: Server Actions
- `app/(main)/*`: หน้าหลังจาก login
- `app/(auth)/*`: หน้า login และสมัครสมาชิก
- `proxy.ts`: redirect ไปหน้า login ถ้ายังไม่มี session
